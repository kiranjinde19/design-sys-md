Design system

This file is the design system for Acme Billing. Stack: Next.js + Tailwind CSS + shadcn/ui. Read all of it before any UI work, copy the classes exactly, and run the Final checklist before saying a screen is done.

Hard rules

  1. Use only the tokens in this file. Never hardcode hex colors, rgb() values or pixel values.
  2. Never use arbitrary Tailwind values such as bg-[#4F46E5] or p-[25px].
  3. One primary button per view. Every other action is secondary or tertiary.
  4. One accent color per screen: the brand color. Status colors only for status.

How to install this file

The tools read plain files. There is nothing to run.

Claude Code, SKILL.md

  1. In your project, create the folder .claude/skills/acme-billing-design-system/.
  2. Save the downloaded file inside it as SKILL.md.
  3. Start Claude Code. It loads the skill when you ask for UI work, or type /acme-billing-design-system.

Codex, AGENTS.md

  1. Save the downloaded file as AGENTS.md in the root of your repository.
  2. Codex reads it at the start of each session. It is plain Markdown, so there is no frontmatter.
  3. Codex reads 32 KiB by default. If you have other AGENTS.md files, check the total, or raise project_doc_max_bytes.

ChatGPT

ChatGPT does not read these files on its own, so you give it the file.

  1. Best: create a ChatGPT Project and upload AGENTS.md to its files.
  2. Quick: paste the whole file at the start of a single chat, then your request.

What ChatGPT accepts changes over time. Check OpenAI's help page "Using Projects in ChatGPT" before relying on a size.

Then: replace or restyle the starter home page your framework creates, because it uses its own colors.
