# Reference mockups

Put the two visual mockups here:

- `Main.dc.html` (board overview)
- `Editor.dc.html` (Colors editor open)
- `ExportView.dc.html` and `ExportViewDark.dc.html` (the Export and Import screen at `/app/export`, light and dark)

They are inline styled markup with the exact sizes, colors and spacing for the tool's own screen at `/app`.
They are read as text only. They are not shipped, imported, linted or included in the production build.

Status: both files are here (copied from Downloads). They are not shipped, imported, linted or built (`design/` is excluded from ESLint and TypeScript). The first comparison against `/app` at 1440px is listed in PROGRESS.md under "Differences from the mockups".

These are the monochrome versions (updated from the newest copies in Downloads): the tool's own interface is black, white and pure gray, and indigo appears only as a sample of the user's brand color.
